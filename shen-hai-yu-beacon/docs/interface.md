# 接口协议说明

## 1. GNSS 模块 (B305-5Q) — 泰斗 SDBP 二进制协议

### 硬件连接
- MCU UART1_TX (PA9) → B305-5Q RXD
- MCU UART1_RX (PA10) → B305-5Q TXD
- MCU PB6 (MCU_EN_PGNSS) → GNSS 电源使能
- 波特率：115200 bps（模块默认），8N1

### SDBP 帧结构
```
帧头(2B)  识别码(2B)  数据长度(2B)  数据(nB)  校验和(2B)
0x23 0x3E  类型 功能    I16U(LE)      ...       Fletcher-16
```

校验范围：识别码 + 数据长度 + 数据

Fletcher-16 算法：
```c
uint16_t cs1 = 0, cs2 = 0;
while (len--) { cs1 += *buf++; cs2 += cs1; }
return (cs2 << 8) | (cs1 & 0xFF);
```

### 使用的指令

| 指令 | 类型/功能 | 说明 |
|------|-----------|------|
| SDBP-CFG-SDBP-I2 | 0x03/0x52 | 打开 LLA3 主动输出 |
| SDBP-CFG-DYNAMIC | 0x03/0x31 | 设置船载运动模型(5) |
| SDBP-DAT-LLA3 | 0x06/0x1D | 接收定位结果(64字节) |

### 打开 LLA3 输出指令
```
发送：23 3E 03 52 05 00 06 1D 01 01 00 <cs_lo> <cs_hi>
数据：类型号=0x06, 语句ID=0x1D, 端口=1(UART1), 频率=1, 保留=0
```

### LLA3 数据结构 (64字节)
| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | I32U | 本地时标 | |
| 4 | I8U | 参考坐标系 | 0=WGS84 |
| 5 | B8 | 有效标识 | BIT0~3=位置类型(3=3D有效), BIT4~7=定位标识(1=公开) |
| 6 | I8U | 跟踪卫星数 | |
| 7 | I8U | 定位卫星数 | |
| 8 | I16U | UTC年 | |
| 10 | I8U | UTC月 | |
| 11 | I8U | UTC日 | |
| 12 | I8U | UTC时 | |
| 13 | I8U | UTC分 | |
| 14 | I16U | UTC秒(ms) | 毫秒表示 |
| 16 | F64 | 经度 | 度，小端 |
| 24 | F64 | 纬度 | 度，小端 |
| 32 | F32 | 高度 | 海平面高度(m) |
| 36 | F32 | 大地水准面修正 | m |
| 40 | I32U | 水平位置精度 | 10^-3 m |
| 44 | I32U | 垂直位置精度 | 10^-3 m |
| 48 | F32 | 地速 | m/s |

## 2. 短报文模块 (TD3203B) — TD3050 ASCII 协议

### 硬件连接
- MCU UART2_TX (PA2) → TD3203B RXD0
- MCU UART2_RX (PA0) → TD3203B TXD0
- MCU PD14 (MCU_EN_PRDSS) → MOD_EN
- 波特率：115200 bps，8N1
- 所有语句末尾加 `\r\n`

### NMEA 校验和
`$` 和 `*` 之间所有字符异或，结果以两位十六进制表示。

### 发送短报文 ($CCTCQ)
```
$CCTCQ,收信方ID,频点,入站确认,编码类别,数据,频度*hh\r\n
```

| 字段 | 取值 | 说明 |
|------|------|------|
| 频点 | 2 | Lf1 |
| 入站确认 | 1 | 不需要确认 |
| 编码类别 | 2 | ASCII代码 |
| 频度 | 0 | 单次发送 |

示例：
```
$CCTCQ,88888888,2,1,2,SOS:30.12345,120.12345,BAT:85%,0*XX\r\n
```

### 发射响应 ($BDFKI)
```
$BDFKI,hhmmss,TCQ,Y/N,失败原因,剩余时间*hh
```
- `Y` = 发射成功
- `N` = 失败，失败原因：1=频率未到, 2=发射抑制, 3=发射静默, 4=功率未锁定, 5=未检测到IC模块, 6=权限不足

### 注入 GNSS 位置 ($CCNPS)
无接收通路时必须注入位置（误差 5 分钟内），否则无法发射：
```
$CCNPS,周内秒,经度(度分),E,纬度(度分),N,高度,M*hh\r\n
```

示例：
```
$CCNPS,100000,12007.41,E,3007.41,N,50.0,M*XX\r\n
```

### 查询本机信息 ($CCICR)
```
发送：$CCICR,0,00*68\r\n
响应：$BDICP,用户ID,通播地址,...*hh
```

### 关闭连续发送 ($CCRMO)
```
$CCRMO,TCQ,1,*0B\r\n   关闭连续TCQ
$CCRMO,EPQ,1,*09\r\n   关闭连续EPQ
```

## 3. USB CDC 配置接口

- PA11 = USB_DM, PA12 = USB_DP
- 插入 Type-C 后电脑识别为 COM 口
- 命令格式：JSON，每条以 `\n` 结尾
- 响应格式：JSON，包含 `ok` 字段

### 命令列表

| 命令 | 方向 | 说明 |
|------|------|------|
| `get_info` | 上位机→MCU | 读取所有基本信息 |
| `get_sn` / `set_sn` | 上位机→MCU | 读写产品序列号 |
| `get_uid` / `set_uid` | 上位机→MCU | 读写唯一识别码 |
| `set_hw_ver` | 上位机→MCU | 写入硬件版本 |
| `get_bdid` | 上位机→MCU | 读取北斗卡号 |
| `get_status` | 上位机→MCU | 读取运行状态 |
| `get_gpio` | 上位机→MCU | 读取三路电源引脚状态 |
| `set_gpio` | 上位机→MCU | 设置三路电源引脚 |
| `enter_dfu` | 上位机→MCU | 进入 Bootloader 升级模式 |

### GPIO 控制命令

三路可控引脚：

| 字段 | 引脚 | 功能 | 高电平 | 低电平 |
|------|------|------|--------|--------|
| `pd14` | PD14 | RDSS 模块使能 (EN_PRDSS) | 开 | 关 |
| `pa2` | PA2 | RDSS PA 5V 电源 (CVPOW5V) | 开 | 关 |
| `pb6` | PB6 | GNSS 模块使能 (EN_PGNSS) | 开 | 关 |

**读取状态：**
```json
{"cmd":"get_gpio"}
```
响应：
```json
{"ok":true,"pd14":0,"pa2":0,"pb6":0}
```

**设置引脚（字段可选，只传需要改变的）：**
```json
{"cmd":"set_gpio","pd14":1,"pa2":1,"pb6":0}
```
响应（回读当前状态）：
```json
{"ok":true,"pd14":1,"pa2":1,"pb6":0}
```

## 4. SWD 调试口 (H1, 5pin)

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | VCC_3V3 | 3.3V 参考 |
| 2 | SWDIO | 数据 |
| 3 | SWCLK | 时钟 |
| 4 | MCU_NRST | 复位 |
| 5 | GND | 地 |

---

## 5. 落水检测

- 引脚：PB7 (KEY_FALL)，低有效
- 持续 500ms 确认，触发 SOS 流程

---

## 6. 磁控开关

- 引脚：PA5 (MCU_MAGKEY)，芯片 RZM001P02T2L
- 长按 3s：启动/停止救援模式

---

## 7. 电池电压监测

- 引脚：PA4 (AD_BAT)，分压 R23=1.2MΩ / R24=3.3MΩ
- 基于 OCV 查表（450mAh 锂电池放电曲线）

| 电量 | 电池电压 |
|------|----------|
| 100% | 4.20V |
| 50% | 3.75V |
| 10% | 3.50V |
| 0% | 3.30V |
